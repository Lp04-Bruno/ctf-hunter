# CTF Hunter 0.1.1 RC1

This candidate fixes the two startup failures found after installing the 0.1.0
Debian package and improves dependency-update validation.

## Fixes

- Builds the Tauri application with its production custom protocol, so the
  installed desktop application loads bundled assets instead of the development
  server at `127.0.0.1:1420`.
- Creates the per-user runtime directory through systemd before applying the
  daemon's filesystem namespace restrictions.
- Accepts reviewed, allowlisted GitHub Action SHA updates while continuing to
  reject floating, inconsistent, or unreviewed action references.
- Uses a fast policy-only pull-request gate for workflow and documentation-only
  changes; source, dependency, build, and packaging changes still run all native
  release gates.

## Install the candidate

Download `ctf-hunter_0.1.1~rc1-1_amd64.deb` and `SHA256SUMS`, verify the package,
then install or upgrade with:

```bash
sha256sum --check --ignore-missing SHA256SUMS
sudo apt install ./ctf-hunter_0.1.1~rc1-1_amd64.deb
```

User data below `~/.local/share/ctf-hunter` is retained during upgrades, removal,
and purge. Terminal capture remains an explicit one-time authorization and still
requires a new login after group enrollment.
