# CTF Hunter 0.1.0 RC2

This is the second installation candidate for CTF Hunter 0.1.0. It retains the
validated application and packaging behavior of RC1 and adds the completed
extended reproducibility gate for the release process.

## Highlights

- Monitors explicitly selected terminal sessions without wrapping the shell or
  target program.
- Watches configured directories and analyzes supported files by content.
- Extracts, recursively decodes, and correlates flag candidates while retaining
  source provenance and transformation history.
- Persists sessions, findings, sources, and notification settings in a local
  SQLite database.
- Provides a native Tauri desktop interface, command-line control client, user
  daemon, and narrowly scoped privileged capture helper.
- Delivers bounded desktop notifications for new findings at the configured
  confidence threshold.
- Verifies the final Debian package across perturbed environment, build path,
  timezone, locale, umask, and file-ordering inputs.

## Install the candidate

Download `ctf-hunter_0.1.0~rc2-1_amd64.deb` and `SHA256SUMS` from this draft or
prerelease, verify the package checksum, then install it with:

```bash
sha256sum --check --ignore-missing SHA256SUMS
sudo apt install ./ctf-hunter_0.1.0~rc2-1_amd64.deb
```

The desktop application works immediately for stored findings, manual analysis,
and file monitoring. Terminal capture requires one explicit authorization through
the in-app setup action. Sign out and back in after enrollment so the new
`ctf-hunter` group membership takes effect.

## Candidate limitations

- This build supports Linux amd64 only and is validated on Debian 12 and Kali
  Rolling. Other distributions and architectures are not part of 0.1.0.
- Terminal capture requires compatible kernel BTF and fentry support. Unsupported
  kernels fail closed while file monitoring and stored data remain usable.
- Directory monitoring is non-recursive and covers direct children of each
  explicitly configured directory.
- HTTP/network collection is not included in 0.1.0; inputs are terminal output,
  watched files, and explicit analysis requests.
- Desktop alerts require an available freedesktop.org notification service. A
  notification failure never blocks collection or analysis and is visible in
  runtime health counters.
- Package downgrade is supported only within database schema generation 4.
- RC checksum evidence is unsigned. The final `v0.1.0` release adds the protected
  OpenPGP checksum signature and signed source tag.
- An APT repository is not enabled for 0.1.0 RC2. Install the downloaded package
  with the local APT command above.

User-owned data below `~/.local/share/ctf-hunter` is retained by both package
removal and purge.
